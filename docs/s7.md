# Le moteur S+7

Module : `src/domain/s7/`. Point d'entrée : `applyS7(text, tagged, options, morphology)`.

## La règle

Chaque nom commun est remplacé par le n-ième lemme suivant dans la liste des noms du
dictionnaire, triée dans l'ordre du dictionnaire français. Le nombre est conservé. Au bout de
la liste, on reprend au début. Un décalage négatif revient en arrière.

Deux modes :

- **même genre** (`same-gender`) : seuls comptent les lemmes qui ont le genre du nom remplacé.
  Le genre du groupe ne change pas.
- **réaccord** (`reagree`) : S+7 strict. On compte tous les lemmes ; le genre du groupe devient
  celui de l'entrée du dictionnaire.

## Les étapes, dans l'ordre

1. **Substitution** (`substitution.ts`) : choix du nouveau lemme, puis de sa forme au nombre voulu.
2. **Accord** (`agreement.ts`) : les adjectifs épithètes contigus au nom prennent le genre du
   groupe. Dans les deux modes, le masculin singulier placé devant voyelle prend sa forme
   particulière (« un bel arbre », « un vieil hôtel »).
3. **Élision et contraction** (`elision.ts`, `determiners.ts`) : le déterminant est réécrit selon
   le genre du groupe et l'initiale du mot qui le suit.

## Le groupe nominal

Le moteur ne fait pas d'analyse syntaxique. Le groupe d'un nom est : le déterminant qui précède
immédiatement, les adjectifs collés au nom avant et après lui, un adverbe pouvant s'intercaler
(« une très vieille ferme », « un horloger très patient »). Une virgule coupe le groupe.

Ne sont pas réaccordés : les attributs (« la maison paraissait grande »), les participes des
temps composés, les adjectifs séparés par une virgule ou une conjonction, les pronoms de
reprise (« elle »). En mode « réaccord », ils restent au genre d'origine.

## Les entités

Définies par des schémas zod dans `types.ts` et `determiners.ts` : `NounForm`, `AdjectiveForm`,
`S7Options`, `Substitution`, `S7Result`, `Determiner`. Les options sont validées à l'entrée du
moteur ; les formes le sont par l'adaptateur qui lit le fichier de morphologie.

Une substitution porte : la position du nom, le mot d'origine, le mot nouveau, un statut
(`replaced`, `unknown-noun`, `missing-form`), et le groupe nominal avant et après.

## Le dictionnaire

Le moteur reçoit la morphologie par le port `MorphologyRepository` (`src/ports/morphology.ts`).
Changer d'implémentation, c'est changer de dictionnaire. Par défaut : les noms du lexique
Grammalecte (`data/morpho-potao.tsv`, MPL 2.0, régénéré par `npm run build:morphology`).

## Limites connues

- Le retour exact (+n puis −n) vaut en mode « même genre », pour les noms dont la forme n'a
  qu'une lecture dans le dictionnaire.
- Un nom épicène (« le livre », « la livre ») ou invariable (« héros ») prend le genre ou le
  nombre de son déterminant ; sans déterminant reconnu, masculin singulier.
- Déterminants pris en charge : le, la, l', les, un, une, des, du, de la, de l', au, à la,
  à l', aux, ce, cet, cette, ces, mon, ma, mes, ton, ta, tes, son, sa, ses, de, d'. Les autres
  (quel, tout, aucun…) sont laissés tels quels.

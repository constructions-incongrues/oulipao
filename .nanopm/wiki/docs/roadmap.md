**Capacity check.** Deux items de code : un S (« Copier ») et un L (le puzzle). Projet solo avec agents, sans méthode ; le code n'est pas la contrainte au rythme constaté. **Exception au refus du partage.** Le lien d'un puzzle transporte sa graine (texte, étiquettes, chaîne) : partage par lien permis pour les seuls puzzles (PRD `mode-puzzle`, tâche 5.2). Le lien partageable d'une entrée du carnet (#95) rejoue une prise ; le partage du texte seul en un clic reste refusé.

## Explicitly NOT on the roadmap

- **Not mesurer la réussite au nombre de textes du fondateur** — les textes sont le sous-produit — reconsider if le fondateur dit revenir pour écrire plutôt que pour jouer ou construire.
- **Not mesurer la construction seule** (commits, moteurs, recettes) — c'est le risque nommé — reconsider if deux semaines de suite comptent des prises hors débogage.
- **Not envoyer un puzzle avant le 20 octobre** — ce serait une relance, et le test ne dirait plus rien — reconsider if le bilan compte au moins 2 blocs revenus.
- **Not le filtrage des mots crus** — ils font partie du rire — reconsider if une prise est mal reçue à cause d'un mot.
- **Not les comptes ni la sauvegarde sur un serveur** — le carnet vit dans le navigateur — reconsider if une prise est perdue faute d'export, ou si le fondateur veut jouer sur deux appareils.
- **Not d'autres langues que le français** — reconsider if le fondateur veut jouer avec un texte dans une autre langue.
- **Not une chaîne par piste** — le S+n réécrit les autres pistes — reconsider if une contrainte ne touche réellement que sa piste.
- **Not la génération de texte par IA** — contraire à « la contrainte est explicite » — pas de réouverture.

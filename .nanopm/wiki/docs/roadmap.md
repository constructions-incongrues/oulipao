## Explicitly NOT on the roadmap

- **Not la génération de texte par IA** — contraire à « la contrainte est explicite » — pas de condition de réouverture
- **Not les comptes ni la sauvegarde sur un serveur** — le texte reste à l'auteur, le carnet vit dans le navigateur — reconsider if le fondateur perd un texte faute de sauvegarde locale ou veut écrire sur deux appareils
- **Not d'autres langues que le français** — le réaccord est déjà un pari dans une seule langue — reconsider if le fondateur veut jouer avec un texte dans une autre langue
- **Not une chaîne par piste** — le S+7 réécrit les autres pistes, deux chaînes parallèles se marcheraient dessus — reconsider if une contrainte ne touche réellement que sa piste et qu'une chaîne parallèle la sert mieux

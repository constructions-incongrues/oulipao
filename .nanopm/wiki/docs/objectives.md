## What's NOT an objective this period

- **Compter les textes du fondateur.** Tentant parce que c'est ce que mesurait le plan du 3 octobre, et que le carnet le permet. Mais le fondateur revient pour l'instrument, et compter ses textes mesurait un désir qu'il n'a pas. Revisit when : il dit revenir pour écrire plutôt que pour jouer.
- **Un résultat clé sur le sens** (« ça veut plus rien dire après », Rozie). Tentant parce que c'est le signal le plus fort non traité. Mais l'instrument est le pari, et le test du lien nu dira si le jeu suffit. Revisit when : le test montre que la seule personne qui revient le fait pour un résultat (l'humeur), pas pour jouer.
- **Un outil à résultat** (« rendre ce texte joyeux » mis en avant). Tentant parce que le V+n le permet déjà et que Rozie le demande. Revisit when : même condition que ci-dessus.
- **Partage du texte seul en un clic (image, aperçu enrichi ; hors puzzles).** Tentant parce que les prises circulent. Mais l'adresse et le bloc du carnet suffisent. Revisit when : quelqu'un renonce à montrer une prise faute de pouvoir la copier. Le lien qui porte une entrée du carnet avec sa chaîne est permis depuis le 2026-10-04 (PR #95) : il fait rejouer la prise, ce que le bloc copié ne fait pas.
- **Format de plugin publié, bac à sable pour plugins tiers.** Tentant parce que c'est la vision d'écosystème. Revisit when : quelqu'un d'autre que le fondateur veut écrire un plugin.
- **Filtrer les mots crus du lexique.** Tentant parce que les prises circulent. Mais ils font partie du rire. Revisit when : une prise est mal reçue à cause d'un mot.
- **Comptes, sauvegarde sur serveur, autres langues.** Revisit when : une prise est perdue faute de sauvegarde locale.
- **Tout ce qui génère du texte par IA.** Anti-persona ; pas de condition de réouverture.

**Action:** Before accepting any new feature request or work item this period, check it against this list. If it matches an anti-goal, the answer is no without a re-prioritization conversation.

# PRD: Lipogramme
Generated by /pm-prd on 2026-10-03

## Problem Statement

La page à pistes n'a qu'une contrainte, le S+7, branchée sur une seule piste : rien n'y montre ce qui distingue une table de mixage d'un générateur, à savoir que des effets se combinent. La roadmap le dit : « une interface à pistes avec un seul plugin ne montre pas la combinaison ». Le contrat de plugin extrait du S+7 (`docs/plugins.md`) n'a été éprouvé que par la contrainte dont il est tiré.

Le lipogramme (un texte privé d'une lettre, comme le « e » de *La Disparition*) est la contrainte que la bidouilleuse imagine juste après le S+7 : dans `personas.md`, Jade « a essayé le S+7, pense à une autre contrainte (lipogramme, boule de neige) et veut la voir tourner dans l'outil ». Aujourd'hui elle l'écrirait dans « un script Python jetable ou un notebook, que personne d'autre ne peut utiliser ».

Aucun retour d'utilisateur ni donnée d'usage n'existe à ce stade.

---

## User Stories

- En tant que lectrice de Perec, je veux interdire le « e » à mon texte et voir chaque mot fautif remplacé par un voisin qui ne le contient pas, pour éprouver *La Disparition* sur mes propres phrases.
- En tant que lectrice de Perec, je veux brancher le S+7 et le lipogramme ensemble et entendre ce que donne leur combinaison, pour jouer de deux règles à la fois comme de deux effets.
- En tant que Jade, bidouilleuse, je veux que le lipogramme soit écrit contre le même contrat que le S+7, pour savoir qu'un plugin que j'écrirai aura sa place de la même façon.

## Scope

### In scope (v1)
- Un plugin « Lipogramme » avec un paramètre « Lettre » (une lettre de a à z, « e » par défaut).
- Le plugin se branche sur un emplacement « Toutes les pistes », sous la table de mixage, comme un effet sur le bus master (décision du fondateur, 2026-10-03).
- Chaque nom, adjectif ou adverbe qui contient la lettre est remplacé par son voisin sans la lettre : même catégorie, mêmes traits (genre et nombre ; les adverbes sont invariables) ; puis la phrase est réaccordée comme pour le S+7.
- Les mots-outils (déterminants, pronoms, prépositions) sont remplacés par un équivalent de même fonction sans la lettre, d'après une table ; s'il n'y en a pas, le mot est retiré.
- Le S+7 et le lipogramme branchés ensemble : le S+7 d'abord, puis le lipogramme ; l'ordre se change.
- Sur la partition, chaque mot remplacé montre son remplaçant ; chaque mot retiré est signalé.
- Le résumé, l'annonce et la mention copiée décrivent la chaîne : « — S+7, parmi tous les noms · lipogramme en e (Potao) ».

### Out of scope (v1)
- Les verbes : ceux qui contiennent la lettre restent tels quels en v1, et le résumé les compte — un second PRD les traitera, une fois leurs formes (mode, temps, personne, nombre) extraites du lexique Grammalecte (décision du fondateur, 2026-10-03).
- Plusieurs lettres interdites à la fois — revisit quand un testeur le demande.
- Les voyelles accentuées : interdire « e » n'interdit ni « é », ni « è », ni « ê » (Perec, lui, les interdisait) — revisit quand la v1 tient ses critères sur le « e » seul.
- Un format de plugin publié : le contrat reste interne (stratégie : trois contraintes d'abord).

## Requirements

### Functional requirements
1. Le plugin « Lipogramme » déclare un paramètre « Lettre » (choix parmi les 26 lettres, « e » par défaut) ; il s'écrit contre `ConstraintPlugin`.
2. Tout nom, adjectif ou adverbe qui contient la lettre est remplacé par le premier mot qui le suit dans l'ordre du dictionnaire, de même catégorie et de mêmes traits, et qui ne contient pas la lettre. Les verbes ne sont pas remplacés en v1.
3. Les noms et adjectifs gardent genre et nombre ; déterminants, adjectifs et pronoms se réaccordent avec les nouveaux noms, comme pour le S+7.
4. Les mots-outils sont remplacés d'après une table d'équivalents sans la lettre, de même fonction ; faute d'équivalent, le mot est retiré et compté.
5. Plusieurs plugins se branchent en chaîne : chacun reçoit la sortie du précédent. Le S+7 passe d'abord par défaut ; l'utilisateur peut inverser l'ordre.
6. Couper le lipogramme, changer de lettre ou changer l'ordre met à jour le texte sans réétiqueter.
7. Le résumé et la mention copiée décrivent toute la chaîne active ; le résumé compte les mots remplacés, retirés, et les verbes qui gardent la lettre.
8. Le lipogramme se branche sur un emplacement « Toutes les pistes », sous les cinq pistes de la table de mixage.

### Non-functional requirements
- Tout s'exécute dans le navigateur ; aucune requête ne contient le texte.
- Contraintes du projet : TypeScript strict, architecture hexagonale, entités validées par schémas zod, couverture supérieure à 90 %.

## The One UX Decision

Où se branche une contrainte qui agit sur toutes les pistes ? Option A : un emplacement « Toutes les pistes » sous la table de mixage, comme un effet sur le bus master. Option B : un emplacement par piste, où l'on branche le lipogramme sur les noms, sur les verbes, etc., séparément.

L'option A dit la vérité de la contrainte (une lettre interdite l'est partout) et ne demande qu'un réglage ; l'option B reste fidèle à la métaphore d'insert sur une piste et permettrait un lipogramme partiel, mais multiplie les réglages.

**Décision du fondateur, 2026-10-03 : option A, le bus master.**

## Summary
Développeuse de la scène creative coding, qui aime les jouets textuels et code sa propre contrainte en une soirée. Porte la vision d'écosystème (plugins, textbanks). Étiquette, pas une personne réelle.

## What we know
**Moment et job**
Elle a essayé le S+7, pense à une autre contrainte (lipogramme, boule de neige) et veut la voir tourner dans l'outil. Elle veut écrire un plugin ou une textbank, le voir marcher tout de suite, le publier, être l'auteure d'une contrainte que d'autres utilisent.
- "le développeur joueur" — personas.md, 2026-10-03

**Contournement actuel**
Un script Python jetable ou un notebook, que personne d'autre ne peut utiliser.

**Bascule**
Déclencheur : un format de plugin lisible en cinq minutes. Frein : format instable ou publication compliquée.

**Signal de reconnaissance**
Elle lit le code source d'un plugin existant et en publie un qui n'est pas de l'équipe d'origine.

**Limite**
Le chemin de Léo à Jade n'est pas établi : rien ne dit que les lecteurs amèneront des développeurs.

**Provenance**
Evidenced : existence du persona (réponse du fondateur). Assumed : tout le détail. Le fondateur a écarté la création sans code par le lecteur et le « moi seul pour l'instant ».

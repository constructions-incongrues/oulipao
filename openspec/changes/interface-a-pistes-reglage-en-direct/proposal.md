# Interface à pistes avec réglage en direct

## Why

Le moteur S+7 n'est visible qu'à travers une page d'essai : une zone de texte, un champ numérique, un texte en sortie. Rien n'y montre l'idée de Potao, à savoir qu'un texte se décompose en pistes linguistiques et qu'une contrainte se branche sur l'une d'elles comme un effet sur une piste de son. Le pari stratégique (c'est l'interface à pistes qui donne envie de revenir) ne peut pas être mis à l'épreuve tant que cette interface n'existe pas.

## What Changes

- Une nouvelle page, distincte de la page d'essai : la partition du texte, en systèmes, avec cinq pistes (noms, verbes, adjectifs, adverbes, autres) où chaque mot est un bloc à sa position.
- Une tranche de réglage par piste : nom, nombre de mots, mute, solo, emplacement de plugin.
- Sur la piste des noms, le plugin S+7 : actif ou coupé, décalage, mode.
- Le texte résultant, mis à jour à chaque geste sans réétiqueter, et un bouton pour le copier.
- États d'attente et d'échec pendant le chargement du modèle et du dictionnaire.
- Le moteur rend sa sortie mot par mot, pour qu'une piste puisse être coupée dans le texte transformé ; le texte qu'il rend ne change pas.

## What's not changing

- Pas de plugin sur les autres pistes : leurs emplacements sont visibles mais vides.
- Pas de choix de l'étiqueteur : le modèle neuronal seul ; la page d'essai reste pour comparer les trois.
- Pas de mise en ligne publique (item 4 de la roadmap).
- Pas de version pour téléphone : écran d'ordinateur, à partir de 1024 pixels.

## Impact

Nouveau dossier `src/ui/tracks/` (état, disposition, composants, page) ; nouveau module `src/domain/mixing.ts` ; `src/domain/s7/engine.ts` et `types.ts` étendus ; `src/ui/page.ts` remanié pour partager son câblage ; nouvelles dépendances `preact`, `htm` et, pour les tests, `preact-render-to-string` ; nouvelle page `tracks.html`.

## Ties to

- Objectif O1 / KR2 (un texte collé est découpé en pistes) ; prépare O2 (cinq personnes l'essaient).
- Roadmap : NOW, item 3, avant le 22 novembre 2026.
- Pari stratégique : c'est l'interface à pistes, et non la contrainte seule, qui donne envie de revenir.

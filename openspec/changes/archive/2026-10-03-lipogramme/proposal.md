# Lipogramme

## Why

La page à pistes n'a qu'une contrainte, branchée sur une seule piste : rien n'y montre que des effets se combinent, ce qui distingue une table de mixage d'un générateur. Le contrat de plugin extrait du S+7 n'a été éprouvé que par la contrainte dont il est tiré. Le lipogramme (un texte privé d'une lettre, comme le « e » de *La Disparition*) est la deuxième contrainte : elle agit sur toutes les pistes et se combine au S+7.

## What Changes

- Un plugin « Lipogramme », avec un paramètre « Lettre » (a à z, « e » par défaut).
- Chaque nom, adjectif ou adverbe qui contient la lettre est remplacé par le premier mot qui le suit dans le dictionnaire, de même catégorie et de mêmes traits, sans la lettre ; la phrase est réaccordée comme pour le S+7.
- Les mots-outils qui contiennent la lettre sont remplacés d'après une table d'équivalents de même fonction ; faute d'équivalent, le mot est retiré et compté.
- Les verbes qui contiennent la lettre restent tels quels et sont comptés.
- Un emplacement « Toutes les pistes » sous la table de mixage, comme un bus master.
- Une chaîne de plugins : le S+7 puis le lipogramme par défaut ; l'ordre se change.
- Le résumé et la mention copiée décrivent toute la chaîne active, avec les décomptes.
- Le contrat de plugin évolue : chaîne, portée « toutes les pistes », mots retirés.

## What's not changing

- Les verbes ne sont pas remplacés : un second PRD les traitera, une fois leurs formes extraites du lexique Grammalecte.
- Une seule lettre interdite à la fois.
- Les voyelles accentuées : interdire « e » n'interdit ni « é », ni « è », ni « ê ».
- Aucun format de plugin publié : le contrat reste interne.

## Impact

Nouveau dossier `src/domain/lipogram/` ; `src/domain/plugin.ts` et `src/domain/s7/` (plugin, et réécriture des noms et réaccord rendus réutilisables) ; `src/ports/morphology.ts` et son adaptateur (adverbes, recherche d'un voisin sans la lettre) ; données dérivées du lexique ; `src/ui/tracks/` (emplacement « Toutes les pistes », chaîne) ; `docs/plugins.md`, `docs/tracks.md`, `RESULTATS.md`.
